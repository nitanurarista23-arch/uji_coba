# My AU Phone

Website demo simulasi iPhone untuk AU interaktif.

## Cara mencoba
Buka `index.html` di browser. Password lockscreen demo: `1234`.

## Cara upload ke GitHub Pages
1. Buat repository baru bernama `my-au-phone`.
2. Pilih **Public** jika ingin menerbitkan lewat GitHub Pages gratis.
3. Upload file `index.html` ke halaman utama repository.
4. Buka **Settings → Pages**.
5. Di bagian Build and deployment, pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/(root)`, lalu tekan **Save**.
7. Tunggu beberapa menit. Link website akan muncul di bagian Pages.

Catatan: semua chat di demo ini berjalan di browser dan belum tersambung ke database. Pesan yang kamu ketik hanya untuk simulasi.
